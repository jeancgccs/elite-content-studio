# Phase 0: Channel Audit (Triage for Stuck Channels)

Use this when a creator arrives without a project: "my channel is stuck",
"nobody watches my videos", "I don't know what to make next", "should I quit?".
Do NOT jump to video ideas — a wrong diagnosis sends them grinding on the wrong
fix for months. Diagnose first, then prescribe.

## Intake (ask for what they can actually get)

Request, in one batched message, whichever of these exist — and proceed with
whatever arrives, stating what's missing and how it limits confidence:

1. Channel basics: niche, age, upload count, cadence, subscriber count.
2. Their 5 most recent titles + thumbnails (screenshots ideal) and 2–3 best
   performers ever.
3. From YouTube Studio (or platform equivalent): views per video, CTR,
   average view duration or % viewed, traffic sources, returning vs new viewers.
4. One sentence: what do they think the problem is, and what have they already tried?
5. Their goal and their honest weekly time budget.

If media/critique material is shared, also apply `content-critique.md` to the
packaging samples — the audit says *which* problem dominates; the critique says
*what to change*.

**Social-first accounts** (Instagram/TikTok primary): run the same triage but
use the social metrics dialect and profile checks from `social-first.md` —
reach/plays, 3s-hold, saves+shares per reach, profile visits → follows — and
include the profile itself as a packaging surface in the diagnosis.

## The four root problems (diagnose in this order)

Almost every stuck channel is stuck for one dominant reason. Identify the
*first* failing layer — fixing downstream layers before upstream ones wastes effort.

### 1. Demand problem — "nobody is looking for this"
Signals: low impressions across all videos; niche is hyper-narrow, undefined, or
drifting (channel is 5 unrelated topics); videos answer questions nobody asks.
Fix at: niche definition + idea selection (`research-ideation.md`). The hard
conversation: some niches can't support growth goals — say so kindly, with options
(adjacent broader niche, format pivot, or accepting a small-audience hobby channel).

### 2. Packaging problem — "shown but not clicked"
Signals: impressions exist but CTR sits below the channel's own norm (or feels
flat across everything); titles are labels not promises ("Vlog #23",
"Minecraft ep 12"); thumbnails are unreadable at feed size or all look identical.
Most common problem for channels under 1k subs.
Fix at: `packaging.md` + retitle/re-thumbnail the best existing evergreen videos
(cheap wins before making anything new).

### 3. Retention problem — "clicked but abandoned"
Signals: healthy CTR but low average % viewed vs. length; first-30s cliffs;
long unedited intros; promise-content mismatch.
Fix at: `scriptwriting.md` hooks + retention architecture, `editing.md` pacing.

### 4. Consistency/authority problem — "good videos, no compounding"
Signals: decent per-video metrics but erratic cadence, no repeated formats, no
series, viewers never return (low returning-viewer share); the channel resets
its audience with every upload.
Fix at: pillar formats, series/clusters, sustainable cadence
(`research-ideation.md` clusters + the 30-day program).

## Audit output format

```
## Channel Audit: [channel]
**Verdict**: Your dominant bottleneck is [one of the four], because [evidence].
  (Secondary: [next layer], to address after.)
**Confidence**: [high/medium/low — and what data would raise it]
**What's actually working**: [2–3 genuine strengths with evidence — always find them]
**What I'd stop doing**: [effort sinks that aren't moving the bottleneck]
**The plan**: [3–5 actions max, ranked, each tied to the bottleneck]
**Quick wins this week**: [repackage old winners, fix one thumbnail, etc.]
**Next**: offer the 30-day program (assets/30-day-program.md) built around the
  bottleneck, and start the channel profile (assets/channel-profile-template.md).
```

## Audit honesty rules

- Small channels have noisy data: under ~1,000 views per video, CTR and retention
  are directional at best — read patterns across many videos, not single uploads,
  and say you're doing so. See `small-channel-playbook.md` for what's signal at
  this size.
- Never diagnose from imagination: if they shared no data, give the *provisional*
  read from titles/thumbnails alone, labeled as such, with the data list to confirm.
- Never soften the diagnosis into "do everything better." One dominant bottleneck,
  one plan. A struggling creator's scarcest resource is focused effort.
- Acknowledge discouragement directly and honestly: consistency through the
  learning curve is the prerequisite for any fix working — but never promise
  timelines or results you can't know.
