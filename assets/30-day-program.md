# 30-Day Improvement Program: [channel]

**Bottleneck being attacked**: [from the channel audit — one only]
**Skill focus this month**: [the one craft skill to practice on every upload]
**Cadence commitment**: [n videos/week — set at 80% of what feels possible]
**Success = inputs shipped** (videos, packaging reps, log entries), not view
targets nobody controls.

## The weekly cycle (repeat ×4)

- [ ] **Review (15 min)**: last video's numbers into the channel profile log —
      pattern read only, no daily checking. What did the retention graph say?
- [ ] **Decide (30 min)**: pick next video from the ranked idea slate; confirm
      it attacks the bottleneck; kill it if it fails the packaging test.
- [ ] **Package first (45 min)**: title options + thumbnail concept BEFORE
      scripting; check at feed size.
- [ ] **Script (1–2 h)**: hook rewritten twice; retention beats marked;
      this month's skill focus applied deliberately.
- [ ] **Shoot & edit**: per production checklist; protect the first 30 seconds
      in the edit above all else.
- [ ] **Publish + promote (30 min)**: SEO package; 1–2 repurposed clips;
      reply to every comment in the first 24–48h.
- [ ] **Log (5 min)**: one lesson into the channel profile. Ship, don't stew.
